# Multimodel Tracker — releases

Signed and notarized builds of **Multimodel Tracker**, a macOS menu-bar app that shows the usage limits of your Claude, ChatGPT/Codex and Google AI accounts in one place.

## Install

1. Download the newest `Multimodel-Tracker-<version>.zip` from [Releases](https://github.com/dev-newb/multimodel-tracker-releases/releases/latest).
2. Unzip it and drag **Multimodel Tracker** into Applications.
3. Open it. Requires macOS 14 or later.

Every build is signed with a Developer ID and notarized by Apple, so it opens without a security warning.

## Updates

From version 1.3.0, the app keeps itself up to date from this repository's latest release (Config → Updates). It installs a download only if it is signed with the project's Developer ID, notarized by Apple, and the version the release says it is.

This repository holds releases only; the source code is kept elsewhere.
